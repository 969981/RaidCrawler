# Upgrade to .NET 10.0

The build fails because the referenced [PKHeX.Core.dll](file:///E:/Github/Pokemon/SaveEditor/RaidCrawler/RaidCrawler.Core/deps/PKHeX.Core.dll) was compiled against `.NET 10.0` (referencing `System.Runtime 10.0.0.0`), while the project targets `.NET 9.0`.

## User Review Required
> [!WARNING]
> This change upgrades the project's **Target Framework** from `net9.0` to `net10.0`.
> This assumes you intend to use the .NET 10 Preview SDK (which appears to be installed based on your path `C:\Program Files\dotnet\sdk\10.0.101\`).

## Proposed Changes
